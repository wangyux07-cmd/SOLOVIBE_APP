# V3-3 交付报告：套餐、时段与预算决策

> 日期：2026-10-13。按 [V3 方案](AI_AGENT_REDESIGNED_PLAN_V3.md) 的 V3-3 开发。**字段契约、失效机制和界面已实现；固定试点中真实、可回溯且仍有效的分店套餐/优惠为 0/1，外部来源验收尚未通过。**V3-2 的分店价目覆盖门槛也仍为 0/3。

## 实现与边界

- `services/offer_policy.py` 对套餐要求明确的名称、人民币价格、使用条款、完整适用门店名及起止日期；时区按上海，终止日的次日零点失效。只有已登记的官网 HTTPS URL、固定高德 POI、页内完整门店名和街道门牌均匹配时，`public_sources.py` 才写入 `offer` Claim。无价格、无条款、错店、未来或过期活动不产生已验证 Claim。Tavily 搜索摘要仍仅作线索。
- 规划时对通过字段级检查的有效套餐给出**单一选项**是否超过用户预算的提示；总活动预算仍为 `unknown`，不会把高德参考人均当成菜单价格。有效套餐可在排序中优先于未知选项；当前无合格套餐时原路线排序不变。
- 高德登记时段与简单 `HH:MM-HH:MM` 时段推测分开输出。推测只描述**生成方案时**是否落在登记时段内，`open_now` 一直为 `unknown`；没有授权的实时营业或座位状态。
- 前端显示套餐价格、条款、适用地点、期限与官方链接；到期后自动隐藏套餐及预算提示，并阻止旧方案准备确认。服务端准备动作也拒绝已过期优惠；用户确认后，行动图再次提取官网并比对价格、条款、适用门店、期限和来源，变化或失败则使动作失效。保存和导航仍不代表下单或预约。

## 真实来源核查

- 当前 12 个固定上海试点的批准来源目录只有[星巴克中国官网早餐菜单](https://www.starbucks.com.cn/menu/food/great-breakfast/)：真实 Tavily 提取到品牌商品，但没有指定分店套餐、价格、使用条件或期限，因此**不产生优惠 Claim**。真实 DeepSeek → LangGraph → 高德 → Tavily → PostgreSQL 复跑得到 3 个星巴克方案，仍为品牌菜单；预算总额与实时营业不被报为已核实。
- [星巴克星享俱乐部规则](https://www.starbucks.com.cn/help/msr/)确有会员优惠券规则，但没有本轮试点分店的固定套餐价格和现时适用期限；不能拿折扣比例或会员权益凑本阶段验收。
- [上海市宝山区政府 2026 年 10 月票根活动](https://www.shanghai.gov.cn/nw17239/20261008/29b613b9aee848579236e8ff0ed574c0.html)列有 2026-10-01 至 2027-01-03 的真实优惠及条件，但地点在宝山，不属于已冻结的徐家汇 12 个试点；未暗中替换试点或把它接到错误门店。
- [Manner 官网](https://www.wearemanner.com/)可用于查门店线索，没有美罗城店当前优惠价目；[上海电影博物馆文旅页](https://www.meet-in-shanghai.net/cn/museum/permanent-exhibition-at-shanghai-film-museum-982968/)是普通票价资料，不是有期限的套餐。旧活动和第三方平台搜索结果均未入库为当前优惠。

## 验证

- `scripts/check.ps1`：**82 项 Python 测试通过**，TypeScript 类型检查与 Vite 生产构建通过。优惠测试覆盖完整来源、缺字段、错店、过期、价格变化、确认前重查以及登记时段不冒充实时营业。
- Playwright 常规浏览器 **6 项通过**，5 项显式依赖真实外部服务的测试按默认配置跳过；其中新增用例确认过期优惠不再显示且旧方案按钮禁用。
- 真实 LangGraph 联调完成：3 个真实星巴克地点、5 个品牌商品示例、0 个分店商品；不把这些商品当优惠。隔离端口的真实浏览器回归 **1 项通过**，官网来源可点、刷新后仍保持品牌与分店区分；浏览器 GPS 为显式注入的测试坐标，不是设备实测定位。

## 未完成的验收与接入方式

V3-3 的外部来源指标仍为 **0/1**。要跨过门槛，需为已冻结试点中的具体门店找到官方或授权、可提取的活动页，同时载明人民币价格、完整门店名、使用条款和有效期。将经过人工核对的 URL 与高德 POI ID 加入批准来源目录后，用真实 Tavily Extract、Claim 入库、预算提示、到期及确认重查做端到端复测。若公开渠道始终没有此类页面，转入 V3-4 的商家合作数据轨；不得用测试页面或跨区活动作为真实试点成绩。
